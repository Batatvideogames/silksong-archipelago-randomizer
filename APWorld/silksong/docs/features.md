## Major Features

### Archipelago Softlock and Hint Window
By pressing F3, you can open up a window that allows you to select a hub to teleport to.

The hub can then be teleported to by clicking the button presented in the menu or pressing F4. 

This is also the same place where you can press hints to view your current hints.

### Archipelago Inventory Section
The in-game inventory has a section that shows a menu to display the archipelago information such as current goal, flea count, silk and soul pre-requisites, melody count, boss credits, and an option to pass time.

https://pandora.auroramoonlight.xyz/q2bOZFm96qlC.mp4

### Combat Logic
The randomizer includes combat logic that can be viewed [here](https://docs.google.com/spreadsheets/d/e/2PACX-1vTTLYgwolonYmtSRzu2AcmxoJu3JKoJAbqRljfavSTgbfYxj5s3u7KbMVPCjikHol9hGrUAK96vCboB/pubhtml#gid=1317856754). 
This is actively being worked on and improved.

### Map Markers
The in-game map has a feature that shows all locations that are available as of the generation of your randomizer. 

The map markers have provisional logic that can be display by F6, do not take these as 100% accurate instead refer to [Universal Tracker](#ut-support).

### Recent Items Display
The randomizer is now built in with a native implementation of a display that shows the last 5 checks the player has received. 

This can be turned on using ModMenu or F9.

### UT Support
The randomizer fully supports [Universal Tracker](https://github.com/FarisTheAncient/Archipelago) and there are zip files available as per each release that can be used with universal tracker to display the current map the player is in.

## Minor Features

### Currency Multiplier
An option is available through generation to multiply currency droppings.

### Faster Animations
Dialogue and silkheart animations can be sped up through generation.

### Link Options
The option to turn on silk link, rosary link, shell shard link, and knockback link is all available through the generation.
Deathlink is also available but toggleable now through the game itself via ModMenu.

### Needle Downgrade
By hovering the needle in the inventory you can press on it to downgrade your needle to make specific skips or tricks easier to do.

### Traps
Traps are applied to generation on filler checks.
These traps include Stagger, Rosary Spill, Darkness, Cursed Crest, Muckmaggot Status, Naked, Literacy, Shader traps.

## Map Changes
- Far Fields - Upper Shaft (Bone_East_11)) has an additional airstream to allow for logic to be available in both states: with the bridge and without the bridge.
- Blasted Steps - Wide Long Vertical (Coral_03) has a room where levers can be hit and all lever platforms will be present, the ones in both states: with levers and without levers.
